Logo Guideline — "Simple"

Based on the Logo chapters of the Brand Guidelines 2035 brochure (Primary Logo, Logo Grid, Logo Variations, Logo Scale, Logo & Signatures).

1. Logo Anatomy
Symbol/Mark: A stylized square icon containing an abstract "Z"-like/lightning motif, set in a red rounded-square container.
Logotype: The wordmark "Simple" in a bold, geometric sans-serif, set directly beside the mark.
Primary lockup: Icon mark on the left + "Simple" wordmark on the right, horizontally aligned, icon roughly the same height as the wordmark's cap-height.
2. Clear Space & Grid
Maintain a minimum clear space around the logo equal to the height of the icon mark (use the icon's own dimension as the spacing unit, per the "Logo Grid" page).
Do not place other text, images, or graphic elements inside this clear-space zone.
The icon mark itself is built on an internal grid — do not redraw or approximate it; always use the master file.
3. Logo Variations

The brochure shows four approved lockups:

Full color on light: Red icon + black "Simple" wordmark — for white/off-white backgrounds.
Full color on dark: Red icon + white "Simple" wordmark — for black backgrounds.
All-black: Black icon + black wordmark — for single-color print or watermark use.
Reversed/white: White icon + white wordmark — for red or dark photographic backgrounds.

Use whichever variant gives the strongest contrast against its background; never place a color-mismatched version on a clashing background.

4. Logo Scale
Main version: Full horizontal lockup (icon + wordmark) — default usage across all applications.
Secondary version: Icon mark alone, used when space is limited (favicons, social avatars, app icons, small merchandise).
Symbol only: The red rounded-square icon may be used standalone once the audience already recognizes the brand (e.g. repeated small placements, watermarks).
Always scale the logo proportionally — never distort width vs. height independently.
Define a minimum size (e.g. do not shrink the full lockup below ~24px height in digital, or ~15mm in print) to keep the wordmark legible.
5. Logo & Signatures
"Signature" usage refers to combining the logo with a tagline or department name stacked below/beside it (e.g. for sub-brands or specific communications).
Keep the same clear-space rule around the full signature block, not just the icon.

7. Typography of the Wordmark
Set in the brand's bold geometric grotesk (same family as headlines: Neue Haas Grotesk Display Pro, Bold).
Tight letter-spacing, no italics, no additional effects (no drop shadow, outline, or gradient).
8. Do's and Don'ts

Do

Use only the provided master logo files.
Maintain minimum clear space and minimum size.
Choose the light/dark/reversed variant based on background contrast.

Don't

Don't recolor the icon or wordmark outside the approved palette.
Don't rotate, skew, stretch, or add effects to the logo.
Don't place the logo on a busy or low-contrast background.
Don't rearrange the icon and wordmark into a new layout not shown in this guide.
Don't substitute the wordmark font with a different typeface.
